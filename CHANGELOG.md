# Historial de cambios

**Compilación:** desde el 26-10-2026 Widget UV se compila y firma solo en el equipo del autor. GitHub guarda el código; no ejecuta compilaciones (se retira el flujo de GitHub Actions).

## 1.5.0 — 26 de octubre de 2026

**Autor: Mosqueteroweb.** Auditoría de accesibilidad: colores de nivel con contraste suficiente en la app y los widgets, TalkBack con frases completas, círculo y consejos que no se rompen con letra grande y widgets con descripción. [Auditoría](docs/1.5.0/AUDITORIA_ACCESIBILIDAD.md).

## 1.4.0 — 26 de octubre de 2026

**Autor: Mosqueteroweb.** Auditoría de UX: sin recargas al cambiar de tema o tamaño de letra, barra de estado visible, coma decimal en español, textos más claros y vistas previas reales de los tres widgets. [Auditoría](docs/1.4.0/AUDITORIA_UX.md).

## 1.3.0 — 26 de octubre de 2026

**Autor: Mosqueteroweb.** Auditoría de seguridad y privacidad: ubicación redondeada a ~1 km antes de enviarla, solo ubicación aproximada, validación de los datos UV, firma permanente, datos fuera de las transferencias entre móviles y GitHub Actions reparado. Quien tenga instalada una versión anterior debe desinstalarla una vez (las anteriores se firmaron con claves temporales). [Auditoría](docs/1.3.0/AUDITORIA_SEGURIDAD.md).
